Visitor agent

What this is. A grounded question-answering prototype for partners. It answers only from what this site already publishes — the thesis copy, the research notes, and the 29 cited sources on the evidence page — and cites what it used.

What it will not do. Anything touching returns, capital requirements, valuation, or terms is refused before retrieval runs and routed to email. That check sits on the raw question, so it cannot be argued around.

Why it has no API key. This page is static. A key in client-side JavaScript would be scraped and billed within days, so retrieval here is deterministic and runs offline. A language model can sit behind a proxy later; the guardrail and grounding boundary stay where they are.
